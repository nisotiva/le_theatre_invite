# LE THÉÂTRE

Интерактивная театральная открытка для Karoline. Отдельный статический сайт: HTML, CSS и JavaScript, локальные шрифты Manrope и Cormorant Garamond с лицензиями OFL.

Содержимое сайта находится в `dist/`. GitHub Actions публикует его в GitHub Pages при изменении ветки `main`. Для локального просмотра достаточно любого статического HTTP-сервера.

Нажатие открывает открытку с небольшим театральным вступлением; повторное складывание доступно кнопкой или Escape. Настройка `prefers-reduced-motion` отключает сценические эффекты. Кнопка «Войти в театр» открывает Discord-приглашение в новой вкладке.
